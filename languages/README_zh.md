# VKT ReadPos — 读位

[English](../README.md) | 中文 | [日本語](README_ja.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

Chrome、Edge 与 Firefox 扩展：记住每个页面读到哪儿，还能把整页状态存成还原点，之后随时放回去。长文读到一半可以续读；仪表盘、填了一半的表单、写到一半的工单这类持有状态的页面，可以存成*还原点*，之后整体放回去。

安装：https://annmax1983.com/extensions/readpos

## 功能

### 阅读位置（免费）

- **按页自动记录** — 停止滚动 600 毫秒后记录一次，切走标签页或关闭页面时再记录一次。
- **续读与自动跳回** — 重新打开同一页时直接滚回上次的位置；别的页面只在右下角显示「继续上次位置 · 62%」，点一下才回去。自动跳回可以在设置里关掉。
- **安静** — 浮标几秒后淡出；把鼠标移到右下角可以让它回来。除此之外不在页面上画任何东西。
- **短页面不打扰** — 低于触发距离（默认 600 像素）的位置不提示。
- **暂停站点 / 清除本页** — 弹窗里各一个按钮。
- **只记你选的站点** — 域名可以手动添加，也可以一键「添加当前站点」；名单外的站点一律不记。没有「记录所有站点」的开关，空名单等于什么都不记。免费。
- **排除某一页，或按正则排除** — 弹窗里的「排除此页面」一键生效：这个地址以后永不记录，同站其它页照常记录。正则规则按地址整段排除，对所有站点生效，不必逐条点名。两个名单都免费，都在完整列表的**排除名单**标签页里管理。
- **最近 20 页历史** — 弹窗只列出当前域名下的页面和到达百分比，点一行即可重新打开。
- **SPA 路由分别记录** — `/app/inbox` 与 `/app/settings` 是两个页面，`#/route` 这类哈希路由同样区分。
- **懒加载页面** — 保存的位置超出当前文档高度时，恢复重试两次，仍够不到就静默放弃。
- **数据可携带** — JSON 导出与导入，免费。
- **恢复前先确认** — 还原之前会列出将被覆盖的内容，免费且默认开启。

### Pro

- **页面还原** — 把滚动位置连同页面上每个表单字段存成一个你起的名字，之后整体放回去。
- **500 页历史**，免费版为 20 页。
- **浮标时序** — 出现延迟、淡出时间、触发距离都可调。
- **每页多个命名还原点** — 每页 1 到 20 个。
- **只读字段** — 可选一并存入还原点。
- **保存快捷键** — 一键保存还原点。
- **还原点跟着导出走** — JSON 文件里位置与还原点都会带上；把还原点导回来需要 Pro。

## 还原点里存了什么

| 元素 | 恢复内容 |
|---|---|
| `input` 文本类（text / email / url / tel / number / search / date…） | 值 |
| `textarea` | 值 |
| `select` | 选中项（找不到值就按选项文字匹配） |
| `select multiple` | 每一个选中项 |
| 组件型下拉（Element Plus、Ant Design、Arco、Naive、Semi、iView） | 选中项的文字 |
| `contenteditable` 富文本编辑器 | 文本内容 |
| open shadow root（Web Components）里的字段 | 值 |
| `checkbox` / `radio` | 选中状态 |
| `details` | 展开 / 折叠 |
| 滚动位置 | 与浮标相同的重试逻辑 |

写入走原生 setter 并派发 `input` / `change`，React / Vue 能感知；框架还是不认，就改用 `insertText` 重新敲一遍。字段定位顺序是「短 CSS 选择器（能穿透 open shadow root）→ id → name 加当前值 → 结构路径」，写回之前还会核对标签文字，表单重排也不会填错框。还有极少数输入框连这也不认，那就用浏览器的 debugger 把文字打进去——连上、插一次、立刻断开；这种组件只认真实输入。

### 不存的

- **密码、文件、隐藏域、一次性验证码、卡号、CVV、IBAN、SSN** — 在采集阶段就排除，没有开关可以重新打开。
- **只读 / 禁用字段** — Pro 可以打开只读字段。
- **`role="tab"` 面板** — 切标签会触发框架自己的加载逻辑，写回去只会打架，宁可留着不做。
- **closed shadow root 与跨域 iframe 内的字段** — 拿不到里面的节点，建不出路径。

## 使用

### 阅读

1. 滚动任意页面，停下，位置就被记住了。
2. 再次回到该页面。同一页会自动滚回上次的位置；不是同一页时，右下角才出现浮标。
3. 出现浮标就点一下滚回去；不理它就会淡出。想每次都手动点，可以在设置里关掉自动跳回。
4. 打开弹窗可以用剩下的功能：**继续阅读**、**在此站点暂停**、**排除此页面**、**清除本页**，以及历史列表。

### 保存还原点（Pro）

1. 把页面调到你想留住的状态。
2. 打开弹窗，点 **保存还原点**，起个名字，保存。若已开启快捷键，也可以直接按快捷键。
3. 之后回到同一页面，弹窗会列出存在这里的每个还原点。
4. 点 **恢复**。面板会列出将被覆盖的内容，确认后所有字段与滚动位置一起回来。

还原点随时可以改：在它那一行上重命名或删除。

### 管理数据

- **历史行** — 点一行重新打开该页；垃圾桶图标只删这一条记录。
- **排除名单标签页** — 完整列表里的独立一栏：粘贴地址加一条，或加一条正则规则；每一条都能在行内删掉。规则还会显示当前命中多少个已存页面。
- **数据区** — 显示存了多少条位置、多少个还原点、占多少空间。
- **清空全部位置** / **删除全部还原点** — 都会先要你确认。
- **导出** 把位置（Pro 还包括还原点）写成 JSON 文件。**导入** 是合并而不是覆盖，同一页面两边都有时保留较新的记录。

### 设置

- **免费** — 暂停站点、排除页面与正则规则、清除本页、导出与导入。
- **Pro** — 浮标延迟、淡出与触发距离；每页还原点上限；只读字段；保存快捷键。

Firefox 上的可选快捷键要在附加组件管理器里设置：**about:addons → 齿轮图标 → 管理扩展快捷键**。

## 权限说明

- **`storage`** —— 位置、还原点、设置与授权状态，只存本地。
- **访问 http 与 https 页面** —— 内容脚本必须在滚动之前就存在，否则没有东西可记。
- **`debugger`** —— 只用一件事：往拒绝一切脚本写入的输入框里打字。连一次、插一次、立刻断开；不读页面内容，也不常驻。
