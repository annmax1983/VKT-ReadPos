# VKT ReadPos — 读位

[English](../README.md) | 中文 | [日本語](README_ja.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

Chrome、Edge 与 Firefox 扩展：记住每个页面读到哪儿，并把「整页现场」保存下来随时恢复。长文读到一半可以续读；仪表盘、填了一半的表单、写到一半的工单这类持有状态的页面，可以存成*现场*，之后整体放回去。

安装：https://annmax1983.com/extensions/readpos

## 功能

### 阅读位置（免费）

- **按页自动记录** — 停止滚动 600 毫秒后记录一次，切走标签页或关闭页面时再记录一次。
- **续读浮标** — 重新打开页面时，右下角出现「继续上次位置 · 62%」。点一下平滑滚回原处，**绝不自动滚动**。
- **安静** — 浮标几秒后淡出；把鼠标移到右下角可以让它回来。除此之外不在页面上画任何东西。
- **短页面不打扰** — 低于触发距离（默认 600 像素）的位置不提示。
- **暂停站点 / 清除本页** — 弹窗里各一个按钮。
- **最近 20 页历史** — 弹窗按到达百分比列出，点一行即可重新打开。
- **SPA 路由分别记录** — `/app/inbox` 与 `/app/settings` 是两个页面，`#/route` 这类哈希路由同样区分。
- **懒加载页面** — 保存的位置超出当前文档高度时，恢复重试两次，仍够不到就静默放弃。
- **数据可携带** — JSON 导出与导入，免费。
- **恢复前先确认** — 恢复现场前会列出将被覆盖的内容，免费且默认开启。

### Pro

- **页面现场** — 把滚动位置连同页面上每个表单字段存成一个你起的名字，之后整体放回去。
- **500 页历史**，免费版为 20 页。
- **浮标时序** — 出现延迟、淡出时间、触发距离都可调。
- **忽略列表** — 支持域名与正则表达式。
- **每页多个命名现场** — 每页 1 到 20 个。
- **只读字段** — 可选一并存入现场。
- **保存快捷键** — 一键保存现场。
- **现场进导出** — JSON 文件里同时包含位置与现场。

| 忽略规则 | 域名 | 域名 **+** 正则表达式 |

## 现场存了什么

| 元素 | 恢复内容 |
|---|---|
| `input` 文本类（text / email / url / tel / number / search / date…） | 值 |
| `textarea` | 值 |
| `select` | 选中项（找不到值就按选项文字匹配） |
| `checkbox` / `radio` | 选中状态 |
| `details` | 展开 / 折叠 |
| 滚动位置 | 与浮标相同的重试逻辑 |

写入走原生 setter 并派发 `input` / `change`，React / Vue 能感知。字段定位顺序是「结构路径 → id → name」，页面轻微重排也能恢复。

### 不存的

- **密码、文件、隐藏域、一次性验证码、卡号、CVV、IBAN、SSN** — 在采集阶段就排除，没有开关可以重新打开。
- **只读 / 禁用字段** — Pro 可以打开只读字段。
- **`role="tab"` 面板、`contenteditable` 富文本编辑器** — 没有既可靠又不破坏框架的写回方式，宁可留着不做。
- **Shadow DOM 内与跨域 iframe 内的字段** — 跨这些边界建不出稳定路径。

## 使用

### 阅读

1. 滚动任意页面，停下，位置就被记住了。
2. 再次回到该页面。若你还在顶部附近，浮标会在稍后出现在右下角。
3. 点它平滑滚回原处；不理它就会淡出。
4. 打开弹窗可以用剩下的功能：**继续阅读**、**在此站点暂停**、**清除本页**，以及历史列表。

### 保存现场（Pro）

1. 把页面调到你想留住的状态。
2. 打开弹窗，点 **保存现场**，起个名字，保存。若已开启快捷键，也可以直接按快捷键。
3. 之后回到同一页面，弹窗会列出存在这里的每个现场。
4. 点 **恢复**。面板会列出将被覆盖的内容，确认后所有字段与滚动位置一起回来。

现场随时可以改：在它那一行上重命名或删除。

### 管理数据

- **历史行** — 点一行重新打开该页；垃圾桶图标只删这一条记录。
- **数据区** — 显示存了多少条位置、多少个现场、占多少空间。
- **清空全部位置** / **删除全部现场** — 都会先要你确认。
- **导出** 把位置（Pro 还包括现场）写成 JSON 文件。**导入** 是合并而不是覆盖，同一页面两边都有时保留较新的记录。

### 设置

- **免费** — 暂停站点、清除本页、导出与导入。
- **Pro** — 浮标延迟、淡出与触发距离；忽略域名与正则；每页现场上限；只读字段；保存快捷键。

Firefox 上的可选快捷键要在附加组件管理器里设置：**about:addons → 齿轮图标 → 管理扩展快捷键**。
