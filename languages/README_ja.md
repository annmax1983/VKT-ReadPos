# VKT ReadPos

[English](../README.md) | [中文](README_zh.md) | 日本語 | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

Chrome・Edge・Firefox 向けの拡張機能。すべてのページで読んでいた位置を覚え、ページの状態そのものを「復元ポイント」として保存し、あとから丸ごと戻します。長い文章の続きから読むための機能と、ダッシュボード・書きかけのフォーム・途中のチケットのような状態を持つページのための機能があります。

インストール：https://annmax1983.com/extensions/readpos

## 機能

### 閲覧位置（無料）

- **ページごとに自動** — スクロールを止めて 600 ミリ秒後に位置を記録し、タブを離れたときや閉じたときにもう一度記録します。
- **続きから・自動復帰** — 同じページを開き直すと、そのまま前回の位置まで戻ります。別のページでは右下に「続きから · 62%」が出て、押したときだけ戻ります。自動復帰は設定でオフにできます。
- **静か** — ピルは数秒で薄れ、右下にポインタを寄せると戻ります。それ以外はページ上に何も描きません。
- **短いページは静かなまま** — しきい値（既定 600 ピクセル）未満の位置は提示しません。
- **サイトの一時停止 / このページを消去** — ポップアップからそれぞれ 1 クリック。
- **選んだサイトだけ記録** — ドメインは手入力でも、「現在のサイトを追加」の 1 クリックでも。リスト外のサイトは記録しません。「すべて記録」に切り替える設定はなく、リストが空なら何も記録しません。無料。
- **1 ページだけの除外、正規表現での除外** — ポップアップの「このページを除外」は 1 クリック。そのアドレスは以後記録せず、同じサイトの他のページは記録を続けます。正規表現ルールはまとめて除外でき、全サイトに効くので 1 件ずつ並べる必要はありません。どちらのリストも無料で、完全なリストの**除外**タブで管理します。
- **履歴 20 ページ** — ポップアップは今いるサイトのページだけを到達率つきで一覧表示し、行をクリックするとそのページを開きます。
- **SPA のルートを区別** — `/app/inbox` と `/app/settings` は別ページ。`#/route` 形式のハッシュルートも同様です。
- **遅延読み込み** — 保存位置が現在の文書高を超えている場合、復元を二度試し、届かなければ静かに諦めます。
- **データを持ち出せる** — JSON の書き出しと読み込みは無料。
- **復元前の確認** — 復元ポイントを戻す前に上書きされる内容を一覧表示します。無料で既定オン。

### Pro

- **ページ復元** — スクロール位置とページ上のすべてのフォーム項目を、付けた名前で保存し、あとからまとめて戻します。
- **履歴 500 ページ**（無料版は 20 ページ）。
- **ピルのタイミング** — 遅延・フェード・しきい値を調整できます。
- **ページごとに複数の名前付き復元ポイント** — 1 ページ 1〜20 個。
- **読み取り専用フィールド** — 任意で復元ポイントに含められます。
- **保存ショートカット** — 復元ポイントをキー 1 つで保存。
- **復元ポイントも書き出しに含まれる** — JSON には位置と復元ポイントの両方が入ります。復元ポイントの読み込みには Pro が必要です。

| | 無料版 | Pro |
|---|---|---|
| 閲覧位置の記録 | ✅ | ✅ |
| 履歴 | 20 ページ | 500 ページ |
| 続きからピル | 固定タイミング | 遅延 / フェード / しきい値を調整可 |
| ページ復元（保存 + 復元） | — | ✅ |
| テキスト欄 / テキストエリア / セレクト / チェックボックス / ラジオ / 開いたパネル | — | ✅ |
| 同一ページの複数の名前付き復元ポイント | — | ✅ |
| 1 ページあたりの復元ポイント上限 | — | 設定可（1〜20） |
| 読み取り専用フィールドを含める | — | 任意 |
| ショートカットで保存 | — | 任意（既定オフ） |
| JSON 書き出し / 読み込み | 位置 | 位置 + 復元ポイント |

ライセンス 1 本で 2 つのブラウザを有効化できます。ライセンスを外すと枠が空きます。

## 復元ポイントに保存されるもの

| 要素 | 復元内容 |
|---|---|
| `input` のテキスト系（text / email / url / tel / number / search / date…） | 値 |
| `textarea` | 値 |
| `select` | 選択中の項目（値で見つからなければ項目名で照合） |
| `select multiple` | 選択したすべての項目 |
| コンポーネント製セレクト（Element Plus、Ant Design、Arco、Naive、Semi、iView） | 選んだ項目名 |
| `contenteditable` リッチテキスト | 本文 |
| オープンな shadow root（Web Components）内の項目 | 値 |
| `checkbox` / `radio` | チェック状態 |
| `details` | 開閉 |
| スクロール位置 | ピルと同じ再試行ロジック |

値はネイティブ setter で書き戻し、`input` / `change` を発火するので React や Vue にも届きます。それでも効かない場合は `insertText` で打ち直します。項目は「短い CSS セレクタ（オープンな shadow root も貫通）→ id → name と現在値 → 構造パス」の順に探し、書き戻す前にラベルの文字を照合するので、並びが変わっても別の欄には入りません。それでも受け付けない入力欄には、ブラウザの debugger で文字を入れます。接続 → 1 回だけ挿入 → 即切断。その種のコンポーネントは本物の入力しか受け付けないからです。

### 保存しないもの

- **パスワード、ファイル、隠しフィールド、ワンタイムコード、カード番号、CVV、IBAN、SSN** — 取得時点で除外します。再有効化する設定はありません。
- **読み取り専用 / 無効な項目** — Pro で読み取り専用を含める設定をオンにした場合を除きます。
- **`role="tab"` パネル** — タブを切り替えるとフレームワーク自身の読み込みが走るため、安全に書き戻せません。
- **クローズドな shadow root とクロスオリジン iframe 内の項目** — 中のノードに届かないため、パスを作れません。

## 使い方

### 読むとき

1. 任意のページをスクロールして止めると、位置が記録されます。
2. そのページに戻ります。同じページなら自動で前回の位置まで戻ります。別のページでは右下にピルが出ます。
3. ピルが出たら押せば元の位置へ戻ります。無視すれば薄れて消えます。自動復帰が不要なら設定でオフにできます。
4. 残りの機能はポップアップから：**続きから読む**、**このサイトで一時停止**、**このページを除外**、**このページを消去**、履歴一覧。

### 復元ポイントを保存する（Pro）

1. ページを残したい状態にします。
2. ポップアップを開き **復元ポイントを保存** を押し、名前を付けて保存。ショートカットを有効にしていればキーでも保存できます。
3. あとで同じページを開くと、保存した復元ポイントがポップアップに並びます。
4. **復元** を押すと、上書きされる内容の一覧が出ます。確認するとすべての項目とスクロール位置が戻ります。

復元ポイントはいつでも編集できます。その行から名前の変更や削除ができます。

### データの管理

- **履歴の行** — クリックでそのページを開き、ゴミ箱アイコンでその 1 件だけ削除。
- **除外タブ** — 完全なリストにあります。アドレスを貼って 1 件追加するか、正規表現ルールを追加。どれも行から削除できます。ルールには現在いくつの保存済みページに当たっているかが出ます。
- **データ欄** — 保存済みの位置の数、復元ポイントの数、使用容量を表示します。
- **すべての位置を消去** / **すべての復元ポイントを削除** — どちらも確認を挟みます。
- **書き出し** は位置（Pro では復元ポイントも）を JSON ファイルにします。**読み込み** は置き換えではなく統合で、同じページに両方あるときは新しい方を残します。

### 設定

- **無料** — サイトの一時停止、ページと正規表現の除外、このページの消去、書き出しと読み込み。
- **Pro** — ピルの遅延・フェード・しきい値、1 ページあたりの復元ポイント上限、読み取り専用フィールド、保存ショートカット。

Firefox では任意のショートカットをアドオンマネージャーで設定します：**about:addons → 歯車アイコン → 拡張機能のショートカットを管理**。

## 権限

- **`storage`** — 位置、復元ポイント、設定、ライセンス状態。すべてローカルです。
- **http / https ページへのアクセス** — スクロールの前にコンテンツスクリプトが存在しないと、覚えるものがありません。
- **`debugger`** — 用途は 1 つだけ。スクリプトからの書き込みを拒む入力欄に文字を入れるためだけに使い、接続 → 1 回挿入 → 即切断します。ページを読むこともしません。
