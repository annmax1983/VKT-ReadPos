# VKT ReadPos

[English](../README.md) | [中文](README_zh.md) | 日本語 | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md)

Chrome・Edge・Firefox 向けの拡張機能。すべてのページで読んでいた位置を覚え、ページの状態そのものを「場面」として保存し、あとから丸ごと戻します。長い文章の続きから読むための機能と、ダッシュボード・書きかけのフォーム・途中のチケットのような状態を持つページのための機能があります。

インストール：https://annmax1983.com/extensions/readpos

## 機能

### 閲覧位置（無料）

- **ページごとに自動** — スクロールを止めて 600 ミリ秒後に位置を記録し、タブを離れたときや閉じたときにもう一度記録します。
- **続きからピル** — ページを開き直すと右下に「続きから · 62%」が出ます。押せばスムーズに戻ります。**勝手にスクロールはしません**。
- **静か** — ピルは数秒で薄れ、右下にポインタを寄せると戻ります。それ以外はページ上に何も描きません。
- **短いページは静かなまま** — しきい値（既定 600 ピクセル）未満の位置は提示しません。
- **サイトの一時停止 / このページを消去** — ポップアップからそれぞれ 1 クリック。
- **履歴 20 ページ** — 到達率つきで一覧表示し、行をクリックするとそのページを開きます。
- **SPA のルートを区別** — `/app/inbox` と `/app/settings` は別ページ。`#/route` 形式のハッシュルートも同様です。
- **遅延読み込み** — 保存位置が現在の文書高を超えている場合、復元を二度試し、届かなければ静かに諦めます。
- **データを持ち出せる** — JSON の書き出しと読み込みは無料。
- **復元前の確認** — 場面を戻す前に上書きされる内容を一覧表示します。無料で既定オン。

### Pro

- **ページ場面** — スクロール位置とページ上のすべてのフォーム項目を、付けた名前で保存し、あとからまとめて戻します。
- **履歴 500 ページ**（無料版は 20 ページ）。
- **ピルのタイミング** — 遅延・フェード・しきい値を調整できます。
- **除外リスト** — ドメインと正規表現に対応。
- **ページごとに複数の名前付き場面** — 1 ページ 1〜20 個。
- **読み取り専用フィールド** — 任意で場面に含められます。
- **保存ショートカット** — 場面をキー 1 つで保存。
- **書き出しに場面も含む** — JSON に位置と場面の両方が入ります。

| | 無料版 | Pro |
|---|---|---|
| 閲覧位置の記録 | ✅ | ✅ |
| 履歴 | 20 ページ | 500 ページ |
| 続きからピル | 固定タイミング | 遅延 / フェード / しきい値を調整可 |
| 除外リスト | ドメイン | ドメイン **+** 正規表現 |
| ページ場面（保存 + 復元） | — | ✅ |
| テキスト欄 / テキストエリア / セレクト / チェックボックス / ラジオ / 開いたパネル | — | ✅ |
| 同一ページの複数の名前付き場面 | — | ✅ |
| 1 ページあたりの場面上限 | — | 設定可（1〜20） |
| 読み取り専用フィールドを含める | — | 任意 |
| ショートカットで保存 | — | 任意（既定オフ） |
| JSON 書き出し / 読み込み | 位置 | 位置 + 場面 |

ライセンス 1 本で 2 つのブラウザを有効化できます。ライセンスを外すと枠が空きます。

## 場面に保存されるもの

| 要素 | 復元内容 |
|---|---|
| `input` のテキスト系（text / email / url / tel / number / search / date…） | 値 |
| `textarea` | 値 |
| `select` | 選択中の項目（値で見つからなければ項目名で照合） |
| `checkbox` / `radio` | チェック状態 |
| `details` | 開閉 |
| スクロール位置 | ピルと同じ再試行ロジック |

値はネイティブ setter で書き戻し、`input` / `change` を発火するので React や Vue にも届きます。項目は「構造パス → id → name」の順に探すため、多少レイアウトが動いても復元できます。

### 保存しないもの

- **パスワード、ファイル、隠しフィールド、ワンタイムコード、カード番号、CVV、IBAN、SSN** — 取得時点で除外します。再有効化する設定はありません。
- **読み取り専用 / 無効な項目** — Pro で読み取り専用を含める設定をオンにした場合を除きます。
- **`role="tab"` パネル、`contenteditable` エディタ** — フレームワークを壊さずに戻す確実な方法がないため、中途半端に実装せず対象外にしています。
- **Shadow DOM 内とクロスオリジン iframe 内の項目** — 安定したパスを作れないため対象外です。

## 使い方

### 読むとき

1. 任意のページをスクロールして止めると、位置が記録されます。
2. そのページに戻ります。まだ上部付近にいる場合、しばらくして右下にピルが出ます。
3. 押せばスムーズに元の位置へ戻ります。無視すれば薄れて消えます。
4. 残りの機能はポップアップから：**続きから読む**、**このサイトで一時停止**、**このページを消去**、履歴一覧。

### 場面を保存する（Pro）

1. ページを残したい状態にします。
2. ポップアップを開き **場面を保存** を押し、名前を付けて保存。ショートカットを有効にしていればキーでも保存できます。
3. あとで同じページを開くと、保存した場面がポップアップに並びます。
4. **復元** を押すと、上書きされる内容の一覧が出ます。確認するとすべての項目とスクロール位置が戻ります。

場面はいつでも編集できます。その行から名前の変更や削除ができます。

### データの管理

- **履歴の行** — クリックでそのページを開き、ゴミ箱アイコンでその 1 件だけ削除。
- **データ欄** — 保存済みの位置の数、場面の数、使用容量を表示します。
- **すべての位置を消去** / **すべての場面を削除** — どちらも確認を挟みます。
- **書き出し** は位置（Pro では場面も）を JSON ファイルにします。**読み込み** は置き換えではなく統合で、同じページに両方あるときは新しい方を残します。

### 設定

- **無料** — サイトの一時停止、このページの消去、書き出しと読み込み。
- **Pro** — ピルの遅延・フェード・しきい値、除外ドメインと正規表現、1 ページあたりの場面上限、読み取り専用フィールド、保存ショートカット。

Firefox では任意のショートカットをアドオンマネージャーで設定します：**about:addons → 歯車アイコン → 拡張機能のショートカットを管理**。
